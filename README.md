# PaMNet-Wheat

Official implementation and dataset for **PaMNet: Parcel-aware Multi-source Wheat Mapping Network**.

> **Coming soon**
>
> The source code, pretrained models, and dataset will be released upon acceptance of the paper.

## Overview

PaMNet is a parcel-aware multi-source framework for parcel-level winter-wheat mapping from high-resolution GF-2 imagery and Sentinel-2 time series.
